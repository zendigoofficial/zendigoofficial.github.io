Player Application

Arcade Scores player profiles are manually approved while the full account system is being planned. Approved players can receive a public profile page with socials, score history, and future live-status support.

Apply now. Full accounts later.

Submit Through Discord → View Players →

Who Should Apply?

Apply if you want to participate in Arcade Scores as a player, submit scores, link your streaming/social profiles, and eventually appear on leaderboard pages.

  • Score Players: users who want to submit arcade or retro scores.
  • Streamers: users who want Twitch or Kick links tied to future live-status features.
  • Community Members: users who want a profile for events, submissions, and score history.
  • Game Hunters: users who want to suggest games and categories.

What Profiles May Include

  • Display Name: public player name.
  • Profile URL: approved player slug.
  • Avatar: profile image or initials placeholder.
  • Bio: short player description.
  • Social Links: Twitch, Kick, YouTube, Speedrun, Steam, X, Bluesky, Facebook.
  • Scores: verified and pending score records.
  • Live Status: Twitch and Kick support planned later.

Application Format

Copy this format and post it through the Arcade Scores Discord workflow. Profile applications are reviewed manually before being added to the website.

PLAYER PROFILE APPLICATION Display Name: Preferred Profile URL / Slug: Discord Username: Short Bio: Main Games / Score Interests: Twitch: Kick: YouTube: Speedrun: Steam: X: Bluesky: Facebook: Other Links: Profile Avatar Link: Are you interested in live score-grind tracking?: Do you agree to follow Arcade Scores rules and proof requirements?: Notes:
Post Application In Discord →

Approval Process

  • Step 1: submit your profile application.
  • Step 2: mods/admins review the profile request.
  • Step 3: approved users can be added to the Players page.
  • Step 4: future verified scores can be connected to the profile.
  • Step 5: full user accounts may replace manual pages later.

Important Notes

Player applications do not automatically create a live account yet. This is the first manual version of the Arcade Scores profile system.

Public player pages should stay clean, accurate, and connected to verified score activity.

Manual profiles now. Real accounts later.
