Resource Structure

Resource files should be grouped by purpose so users can quickly find setup help, submission tools, rules, and support files.

  • Path format: downloads/resources/category-folder/
  • Example: downloads/resources/rulesets/
  • Allowed files: ZIP, PDF, TXT, MD, PNG, JPG, JPEG, WEBP
  • Readme rule: ZIP packs should include a readme whenever users need instructions.

Resource Entry Format

  • Title: resource name.
  • Category: guide, ruleset, template, config, save, or setup pack.
  • Version: version or date.
  • Related System: arcade, NES, SEGA, PC / DOS, etc.
  • Related Game: if specific to one game.
  • Notes: setup or usage instructions.

Resource Upload Plan

When a resource file is uploaded to the correct folder, this page can list it without a manual page rewrite.

  • Upload path: downloads/resources/category-folder/file-name.ext
  • Recommended filename: category_resource-name_version.ext
  • Example: rulesets_donkey-kong_arcade-v1.pdf
  • Allowed extensions: .zip, .pdf, .txt, .md, .png, .jpg, .jpeg, .webp
  • Fallback: if no files exist yet, the page displays a pending message.
