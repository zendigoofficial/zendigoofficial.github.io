Resource Structure

Resource files should be grouped by purpose so users can quickly find setup help, submission tools, rules, and support files.

  • Guides: downloads/resources/guides/
  • Download Instructions: downloads/resources/download-instructions/
  • Rulesets: downloads/resources/rulesets/
  • Score Templates: downloads/resources/score-templates/
  • Controller Configs: downloads/resources/controller-configs/
  • Setup Packs: downloads/resources/setup-packs/
  • Save Files, if allowed: downloads/resources/saves/

Resource Entry Format

  • Title: resource name.
  • Category: guide, ruleset, template, config, save, or setup pack.
  • Version: version or date.
  • Related System: arcade, NES, SEGA, PC / DOS, etc.
  • Related Game: if specific to one game.
  • Download: file link once uploaded.
  • Notes: setup or usage instructions.

ZIP Upload Plan

Resources can be uploaded as ZIP files, PDFs, text files, images, or plain HTML guides depending on what they need to do.

  • Recommended filename: category_resource-name_version.zip
  • Example: rulesets_donkey-kong_arcade-v1.zip
  • Link style: ../downloads/resources/rulesets/rulesets_donkey-kong_arcade-v1.zip
  • Readme rule: ZIP packs should include a readme whenever users need instructions.
  • Update needed: add the resource to Current Resource Index and update the related category card.
