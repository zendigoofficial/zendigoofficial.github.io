Upload Structure

Game ZIPs should be uploaded into system-specific folders so this page can find them automatically.

  • Path format: downloads/roms/system-folder/
  • Example: downloads/roms/sega-genesis/
  • File type: .zip
  • Recommended filename: system_game-title_version.zip
  • Example: sega-genesis_homebrew-title_v1.zip

Game File Entry Format

  • Game Title: exact title.
  • System: platform or console.
  • File Type: ROM, demo, homebrew, public domain, patch, or package.
  • Version / Region: if relevant.
  • Legal Status: approved for use/distribution.
  • Scoreboard: available, planned, or not applicable.

ZIP Upload Plan

When a legal-to-use ROM or game-file ZIP is uploaded to the correct folder, this page can list it without a manual page rewrite.

  • Upload path: downloads/roms/system-folder/file-name.zip
  • Only ZIP files display: README files and other files are ignored.
  • System cards: click a card to fetch that system folder from GitHub.
  • Alphabet filter: after loading a system, filter by the first letter of the filename.
  • Fallback: if no ZIPs exist yet, the page displays a pending message.
