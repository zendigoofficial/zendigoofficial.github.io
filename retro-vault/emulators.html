Upload Structure

Emulator ZIPs should be uploaded into system-specific folders so this page can find them automatically.

  • Path format: downloads/emulators/system-folder/
  • Example: downloads/emulators/sega-genesis/
  • File type: .zip
  • Recommended filename: system_emulator-name_version.zip
  • Example: sega-genesis_emulator-pack_v1.zip

Emulator Entry Format

  • System: platform or console.
  • Recommended Emulator: preferred emulator package.
  • Version: package version or build date.
  • BIOS: required, not required, or varies.
  • Controller Notes: setup guidance.
  • Score Compatibility: whether it fits Arcade Scores tracking.

ZIP Upload Plan

When an emulator ZIP is uploaded to the correct folder, this page can list it without a manual page rewrite.

  • Upload path: downloads/emulators/system-folder/file-name.zip
  • Only ZIP files display: README files and other files are ignored.
  • System cards: click a card to fetch that system folder from GitHub.
  • Fallback: if no ZIPs exist yet, the page displays a pending message.
