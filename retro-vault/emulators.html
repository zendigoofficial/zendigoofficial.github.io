Upload Structure

Emulator ZIPs should be uploaded into system-specific folders so links stay clean and predictable.

  • Arcade: downloads/emulators/arcade/
  • NES: downloads/emulators/nes/
  • SNES: downloads/emulators/snes/
  • Genesis: downloads/emulators/genesis/
  • Sega CD: downloads/emulators/sega-cd/
  • Master System: downloads/emulators/master-system/
  • Game Boy: downloads/emulators/game-boy/
  • PC / DOS: downloads/emulators/pc-dos/

Emulator Entry Format

  • System: platform or console.
  • Recommended Emulator: preferred emulator package.
  • Version: package version or build date.
  • Download: ZIP file link once uploaded.
  • BIOS: required, not required, or varies.
  • Controller Notes: setup guidance.
  • Score Compatibility: whether it fits Arcade Scores tracking.

ZIP Upload Plan

When an emulator ZIP is uploaded, use a predictable filename and place it in the matching system folder.

  • Recommended filename: system_emulator_name_version.zip
  • Example: genesis_exampleemulator_v1.zip
  • Link style: ../downloads/emulators/genesis/genesis_exampleemulator_v1.zip
  • Update needed: replace “ZIP Pending” with “Available” and point the card link directly to the ZIP.
